# Analyse-powerbi-developpement-humain-co2-europe
Projet Power BI d’analyse de la relation entre le développement humain et les émissions de CO₂ dans les pays européens de 2004 à 2023. Comprend le nettoyage et la transformation des données, la création de mesures DAX et la conception de tableaux de bord interactifs pour explorer les enjeux socio-économiques et environnementaux.
